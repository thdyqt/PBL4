SẴN SÀNG

Trình duyệt Chrome / Edge sẽ tự động gửi URL và tên file qua cổng này ngay khi người dùng nhấn tải file trên web.

Hướng dẫn cài đặt Extension cho Chrome / Edge (3 bước)
1
Mở trang quản lý Tiện ích mở rộng của Trình duyệt
Mở Chrome và truy cập chrome://extensions hoặc Edge edge://extensions, sau đó bật công tắc "Chế độ dành cho nhà phát triển" (Developer mode) ở góc trên bên phải.
2
Nạp tiện ích đã giải nén (Load Unpacked)
Bấm nút "Tải tiện ích đã giải nén" (Load unpacked) và chọn thư mục BrowserExtension của dự án.
3
Trải nghiệm bắt link tự động
Bấm vào bất kỳ link tải tệp (.zip, .iso, .exe, .mp4, .pdf...) hoặc nhấp chuột phải chọn "Tải bằng DUT Download Accelerator", liên kết sẽ được tự động chuyển ngay về app!

Xác nhận trước khi xóa tệp
Hiển thị hộp thoại xác nhận khi bạn xóa tệp hoặc xóa tất cả tệp khỏi danh sách. Bỏ chọn nếu bạn muốn xóa ngay mà không cần xác nhận lại.
Tích hợp hệ điều hành Windows (Windows Shell)
Tùy biến hành vi hệ điều hành: Chạy nền trên khay hệ thống, khởi động cùng Windows và thông báo khi tải xong.
Khởi động cùng Windows (Run on Startup)
Tự động khởi chạy DUT Download Accelerator ngầm trên khay hệ thống khi bạn đăng nhập Windows (Registry HKCU\Run).
Thu nhỏ xuống khay hệ thống khi đóng [X]
Khi bấm dấu [X] tắt ứng dụng, app sẽ thu nhỏ xuống khay hệ thống (System Tray) để tiếp tục tải ngầm thay vì tắt hẳn.
Thông báo Windows khi tải xong (Toast Notification)
Hiển thị thông báo Toast / BalloonTip ở góc phải màn hình khi tệp hoàn tất, bấm vào thông báo để mở tệp ngay.
